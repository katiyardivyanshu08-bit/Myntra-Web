# Myntra_Web
# Myntra Clone Project

A clean, responsive, and visually appealing e-commerce storefront landing page built using semantic HTML5 and modern CSS3 (including Flexbox and Grid layouts). This project is designed as a recreation of the popular fashion platform, Myntra.

## 🚀 Features

* **Responsive Top Navigation Bar:** Features an interactive product search field, brand categorical menus, and actionable utility icons (Profile, Wishlist, Bag).
* **Dynamic Promotional Banners:** Implements high-impact promotional strips and full-width seasonal hero banners.
* **Modern CSS Grid Component:** Includes a curated grid displaying special product categories and price thresholds with overlaid tag markers.
* **Clean Assets Integration:** Powered by optimized imagery alongside scalable FontAwesome iconography.

---

## 🛠️ Built With

* **HTML5:** Structured semantic markup.
* **CSS3:** Custom layouts utilizing Flexbox, CSS Grid, custom gradient components, and typography mappings.
* **FontAwesome:** Vector icons for global user interface tools.
